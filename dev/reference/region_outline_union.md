# Region outlines unioned.

An [`sf::sf`](https://r-spatial.github.io/sf/reference/sf.html) object
containing outlines for major regions. Each outline is represented as a
single polygon. If you want multiple polygons, use
[region_outline](https://evolecolgroup.github.io/pastclim/dev/reference/region_outline.md).

## Usage

``` r
region_outline_union
```

## Format

[`sf::sf`](https://r-spatial.github.io/sf/reference/sf.html) of
outlines.

- name:

  names of regions
