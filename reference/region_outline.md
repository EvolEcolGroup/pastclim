# Region outlines.

An [`sf::sf`](https://r-spatial.github.io/sf/reference/sf.html) object
containing outlines for major regions. Outlines that span the
antimeridian have been split into multiple polygons.

## Usage

``` r
region_outline
```

## Format

[`sf::sf`](https://r-spatial.github.io/sf/reference/sf.html) of
outlines.

- name:

  names of regions
