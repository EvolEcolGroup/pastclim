# Time boundaries of marine isotope stages (MIS).

A dataset containing the beginning and end of MIS.

## Usage

``` r
mis_boundaries
```

## Format

A data frame with 24 rows and 2 variables:

- mis:

  the stage, a string

- start:

  the start of a given MIS, in kya

- end:

  the start of a given MIS, in kya
